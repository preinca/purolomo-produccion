# Reglas para el asistente

Edita este archivo. En este proyecto estas reglas se cumplen en cada pedido.

Si una regla de aquí choca con lo que pides en un mensaje, gana ese mensaje.

La copia que Cursor aplica en cada conversación está en `.cursor/rules/reglas.mdc`. Si cambias una regla aquí, pide que se actualice también ese archivo.

## Cómo agregar una regla

Añade una línea nueva en la lista de abajo. Escríbela como una orden corta, en español.

## Reglas vigentes

1. Responde en español.
2. No uses subagentes para validar, probar pantallas ni revisar flujos, salvo que yo lo pida explícitamente en ese mensaje.
3. Haz el cambio y responde directo. No recorras la aplicación pantalla por pantalla para comprobar que todo funciona, salvo que yo lo pida explícitamente.
4. No alargues la respuesta con pasos de verificación que no pedí.
5. Vas a trabajar desde el proyecto que está ubicado en la dirección de esta computadora: C:\Users\mende\OneDrive\Documents\PREINCA\PUROLOMO PRODUCCION\purolomo-produccion, para que hagas todos los cambios desde allí de manera local.
